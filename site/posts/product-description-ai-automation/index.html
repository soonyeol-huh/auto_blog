신상품 올릴 때마다 상세 설명을 처음부터 쓰고 계신가요?

새 상품이 들어오면 사양서와 사진을 보며 상품명을 짓고, 특징을 정리하고, 판매 채널마다 형식에 맞춰 상세 설명을 다시 쓰는 회사가 많습니다. 상품 설명은 상품마다 내용만 다를 뿐 들어가야 할 항목과 구성은 거의 같기 때문에, 정보만 정리돼 있으면 AI가 초안을 만들고 사람은 확인만 하는 구조로 바꿀 수 있습니다. 이 글은 상품 기본 정보 정리부터 채널별 초안 생성, 검사와 검토, 등록 후 관리까지 어떻게 자동화하는지 정리했습니다.

상품 설명 작성이 왜 매번 병목이 될까

신상품 하나를 판매 채널에 올리려면 상품명, 핵심 특징, 상세 설명, 사양표, 사용·세탁·보관 주의사항, 검색 키워드까지 채워야 합니다. 정보는 공급처 사양서, 담당자 메모, 사진, 이전 시즌 상품 페이지에 흩어져 있고, 작성자는 그것을 모아 읽고 문장으로 다시 씁니다. 채널이 여러 개라면 상품명 길이 제한, 필수 입력 항목, 문체가 채널마다 달라서 같은 내용을 여러 번 고쳐 씁니다. 상품 수가 적을 때는 버틸 수 있지만, 시즌마다 수십·수백 개가 한꺼번에 들어오면 등록이 밀리고 판매 시작도 함께 늦어집니다.

손으로 쓰면 생기는 문제

  • 등록이 늦어집니다. 상품은 입고됐는데 상세 설명이 준비되지 않아 판매를 시작하지 못하는 기간이 생깁니다.
  • 상품마다 품질이 들쭉날쭉합니다. 누가 썼는지, 얼마나 바빴는지에 따라 어떤 상품은 정보가 꼼꼼하고 어떤 상품은 핵심 사양이 빠집니다.
  • 채널마다 정보가 어긋납니다. 한 채널에서 사이즈나 구성품을 고쳤는데 다른 채널은 그대로 남아 고객 문의와 반품으로 이어집니다.
  • 확인되지 않은 표현이 섞입니다. 급하게 쓰다 보면 근거 없는 최상급 표현이나 확인하지 않은 효과 문구가 들어가기 쉽습니다.

이 문제들은 작성자의 문장력 문제가 아니라, 정리되지 않은 정보를 매번 사람이 처음부터 문장으로 옮기는 구조에서 생깁니다.

자동화 구조는 네 단계로 나뉜다

  1. 상품 기본 정보 정리. 상품코드, 소재, 사이즈, 구성품, 원산지, 주의사항처럼 사실에 해당하는 항목을 상품 마스터 한 곳에 정해진 형식으로 모읍니다. 공급처 사양서나 기존 상세 페이지에서 항목을 뽑아내는 데 AI를 쓸 수 있습니다.
  2. 채널별 초안 생성. 상품 마스터의 정보만 입력으로 넣고, 채널별 템플릿(상품명 길이, 필수 항목, 문체)에 맞춰 AI가 상품명과 상세 설명 초안을 만듭니다.
  3. 규칙 검사와 담당자 검토. 필수 항목 누락, 글자 수 초과, 회사가 정한 금지 표현, 마스터에 없는 수치가 들어갔는지를 규칙으로 검사하고, 담당자가 최종 확인합니다.
  4. 등록과 이후 관리. 확정된 내용을 채널에 등록하고, 상품 마스터가 바뀌면 어느 채널의 어떤 문구를 고쳐야 하는지 알려 줍니다.

핵심은 사실은 마스터에서, 문장은 AI가, 확정은 사람이 맡도록 나누는 것입니다.

소재·사이즈·구성품 같은 사실 값상품 마스터모든 채널에서 같은 값이 나와야 함

글자 수·필수 항목·금지 표현 검사규칙매번 같은 기준으로 빠짐없이 확인해야 함

AI에게 주는 입력이 결과를 결정한다

AI에게 "이 상품 설명 써 줘"라고만 하면, 그럴듯하지만 실제 상품에 없는 장점이 섞인 문장이 나오기 쉽습니다. 안정적인 결과를 얻으려면 입력과 지시를 정해 두어야 합니다. 상품 마스터의 항목을 그대로 넣고, 그 안에 없는 기능·수치·효과는 쓰지 말라고 명시하고, 채널별로 문단 구성과 길이를 고정합니다. 잘 팔리는 기존 상품의 상세 설명 몇 개를 예시로 함께 주면 회사의 문체도 유지됩니다. 그리고 생성된 문장 속 숫자와 소재명이 마스터 값과 일치하는지를 자동으로 대조하면, 사람이 확인해야 할 부분이 크게 좁혀집니다.

담당자가 고친 내용을 다시 반영하세요. 검토 과정에서 자주 고치는 표현은 금지 표현 목록이나 템플릿 지시에 추가하고, 자주 빠지는 정보는 마스터의 필수 항목으로 올립니다. 그러면 시간이 지날수록 손볼 곳이 줄어듭니다.

도입 전 체크리스트

  • 상품마다 공통으로 필요한 정보 항목이 정해져 있나요? 없다면 그것부터 정해야 합니다.
  • 상품 정보의 원본이 어디인지(공급처 사양서, 내부 엑셀, ERP) 정리되어 있나요?
  • 채널별 상품명 길이, 필수 항목, 문체 기준을 적어 둘 수 있나요?
  • 회사가 쓰지 않기로 한 표현이나 반드시 확인이 필요한 표현 목록이 있나요?
  • 최종 확인을 누가 하는지, 확인 없이 등록되는 경우가 없도록 정했나요?

자주 하는 실수

  • 상품 정보 정리 없이 AI 작성부터 시작하는 것 — 입력이 부정확하면 AI는 틀린 내용을 더 매끄러운 문장으로 만들 뿐입니다.
  • 사진만 보고 설명을 쓰게 하는 것 — 색상, 소재, 크기는 사진만으로 정확히 판단하기 어렵습니다. 사진은 보조 자료로만 씁니다.
  • 검토 없이 바로 등록하는 것 — 한 번 잘못 등록된 정보는 고객 문의와 반품으로 돌아옵니다.
  • 등록 후 수정을 채널마다 따로 하는 것 — 마스터를 고치지 않고 채널에서만 고치면 정보가 다시 어긋납니다.

FAQ

AI가 쓴 상품 설명을 그대로 올려도 되나요?

권장하지 않습니다. AI는 주어진 정보를 그럴듯한 문장으로 바꾸는 데 강하지만, 입력에 없는 기능이나 효과를 덧붙이는 경우가 있습니다. 사양과 수치는 상품 마스터에 있는 값만 쓰도록 제한하고, 규칙 검사를 통과한 초안이라도 담당자가 한 번 확인한 뒤 등록하는 구조가 안전합니다. 특히 효능, 인증, 원산지처럼 사실 확인이 필요한 표현은 반드시 사람이 확인해야 합니다.

상품 정보가 엑셀 여러 개에 흩어져 있는데 시작할 수 있나요?

가능합니다. 다만 AI 작성보다 상품 기본 정보를 한 곳에 모으는 일이 먼저입니다. 상품코드, 상품명, 소재, 사이즈, 구성품, 주의사항처럼 모든 상품에 공통으로 필요한 항목을 정하고, 신상품부터 그 형식으로 채우는 것으로 시작하면 됩니다. 기존 상품은 상세 페이지 문장에서 AI로 항목을 뽑아 정리하는 방식으로 점차 옮길 수 있습니다.

판매 채널마다 글자 수와 형식이 다른데 어떻게 맞추나요?

상품 정보와 채널별 형식을 분리해서 관리하면 됩니다. 정보는 상품 마스터 한 곳에 두고, 채널마다 상품명 길이, 필수 항목, 문체, 금지 표현을 템플릿으로 정해 두면 같은 정보로 채널별 초안을 따로 만들 수 있습니다. 처음에는 매출 비중이 가장 큰 채널 하나로 시작하고 하나씩 늘리는 편이 현실적입니다.
