AI 자동화 상담 전에 이것부터 그려보세요: 업무 흐름 한 장 정리법

“우리 회사에도 AI를 넣고 싶은데 뭘 설명해야 할지 모르겠다”면 기능 목록부터 만들지 않아도 됩니다. 지금 사람이 하는 일을 입력 → 처리 → 판단 → 출력 → 예외 순서로 한 장에 적어보면 자동화할 지점이 훨씬 선명해집니다.

“AI로 뭘 만들까요?”보다 먼저 물어야 할 것

AI 자동화 상담에서 흔히 나오는 첫 문장은 “챗봇을 만들고 싶어요”, “보고서를 AI가 써주면 좋겠어요” 같은 기능 이야기입니다. 하지만 실제 구축에서는 그 기능 앞뒤의 업무가 더 중요합니다.

예를 들어 보고서 작성만 자동화해도 숫자를 누가 어디서 가져오는지, 누가 오류를 확인하는지, 최종 결과를 어디에 올리는지에 따라 필요한 시스템이 완전히 달라집니다. 그래서 먼저 현재 업무의 이동 경로를 그리는 편이 좋습니다.

업무를 다섯 칸으로만 나눠보세요

구분적어볼 질문예시
입력일이 무엇 때문에 시작되나?주문 발생, 메일 도착, 엑셀 업로드
처리사람이 반복해서 무엇을 하나?복사, 조회, 정리, 계산
판단어떤 기준으로 다음 행동을 정하나?재고 부족, 금액 기준, 문의 유형
출력결과를 어디에 남기나?ERP 입력, 메일 발송, 보고서 저장
예외평소와 다르면 누가 무엇을 하나?담당자 확인, 승인 요청, 수동 수정

실제 예시: 매일 아침 재고 부족 상품을 찾는 팀

한 온라인 판매팀이 매일 아침 전날 주문 파일을 내려받고, ERP 재고를 조회한 뒤, 재고가 부족한 상품을 거래처에 문의한다고 해보겠습니다.

입력 주문 파일이 생성됨 → 처리 주문량과 ERP 재고를 맞춤 → 판단 예상 재고가 기준 이하인지 확인 → 출력 부족 상품 목록 작성 → 예외 중요 상품은 팀장 확인 후 거래처 문의

이렇게 적으면 “AI가 재고를 관리한다”라는 막연한 요구가 여러 작은 문제로 나뉩니다. 주문 파일 수집과 재고 계산은 일반 자동화가 잘하는 영역이고, 거래처 답변을 읽어 납기 유형을 분류하는 일은 AI가 도움이 될 수 있습니다. 중요한 발주 결정은 사람이 승인하도록 남길 수도 있습니다.

한 장을 그리면 자동화 범위가 보입니다

반복되는 이동은 연결 후보입니다

엑셀에서 값을 복사해 ERP에 넣거나, 쇼핑몰에서 숫자를 보고 메신저에 적는 단계가 반복된다면 API, 파일 연동, 브라우저 자동화 같은 연결 방법을 검토할 수 있습니다.

규칙이 명확한 판단은 먼저 규칙으로

“재고가 10개 아래면 표시”처럼 기준이 명확한 일은 굳이 AI에게 맡길 이유가 없습니다. 계산과 조건문으로 처리하는 편이 결과를 설명하고 검증하기 쉽습니다.

문맥이 필요한 판단에 AI를 검토합니다

고객 문의의 의도를 분류하거나 긴 메모에서 핵심 사유를 찾는 것처럼 문장의 맥락을 이해해야 하는 단계가 AI 후보입니다. AI가 모든 단계를 맡는 것이 아니라 필요한 구간에 들어가는 구조입니다.

자동화 상담 전에 준비하면 좋은 최소 정보

완성된 기획서가 없어도 됩니다. 담당자 한 명이 실제 화면을 보면서 아래 내용을 설명할 수 있으면 시작하기 좋습니다.

사람이 판단하는 기준규칙 자동화와 AI 적용 영역을 나누기 위해
자주 생기는 예외실제 운영에서 멈추지 않는 구조를 설계하기 위해

좋은 자동화는 사람을 지우는 것이 아닙니다

업무 흐름을 그리는 이유는 모든 칸에서 사람을 없애기 위해서가 아닙니다. 컴퓨터가 안정적으로 할 수 있는 반복 작업은 줄이고, 금액·고객·계약처럼 영향이 큰 판단에는 사람이 남도록 경계를 정하기 위해서입니다.

이 한 장은 개발사나 FDE와 대화할 때도 유용합니다. “AI 기능 하나”를 주문하는 대신, 현재 업무에서 어디가 느리고 어떤 데이터를 쓰며 어디까지 자동 실행해도 되는지를 함께 논의할 수 있기 때문입니다.

FAQ

업무 흐름을 정리하려면 전문적인 프로세스 문서가 필요한가요?

아닙니다. 처음에는 입력, 처리, 판단, 출력, 예외 다섯 항목만 적어도 충분합니다. 실제 담당자가 하는 순서와 예외를 빠뜨리지 않는 것이 더 중요합니다.

업무 흐름을 정리하면 바로 AI를 붙일 수 있나요?

항상 그렇지는 않습니다. 규칙이 명확한 단계는 일반 자동화가 더 적합할 수 있고, 문장 이해나 분류처럼 맥락 판단이 필요한 단계에 AI가 유용할 수 있습니다.

어떤 업무부터 그려보는 것이 좋나요?

여러 사람이 반복하고, 엑셀이나 메신저를 오가며, 누락이나 재확인이 자주 생기는 업무부터 시작해보세요. 흐름이 자주 반복될수록 개선 전후를 비교하기도 쉽습니다.
